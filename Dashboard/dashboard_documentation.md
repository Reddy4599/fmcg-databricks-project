# FMCG Analytics Dashboard

## Overview

The dashboard provides business-level insights from the Gold-layer FMCG datasets processed in Databricks.

## Dashboard Sections

### Sales Performance
- Total sales
- Monthly sales trends
- Sales performance over time

### Product Analysis
- Top-performing products
- Product-level sales
- Product contribution

### Category Analysis
- Sales by category
- Category performance comparison

### Customer Analysis
- Customer-level sales
- Top customers
- Customer contribution

### Channel Analysis
- Sales by channel
- Channel performance comparison

## Data Source

The dashboard uses curated Gold-layer datasets generated by the Databricks data pipeline.

## Architecture

Source Data
→ Bronze
→ Silver
→ Gold
→ Dashboard

## Tools

- Databricks
- PySpark
